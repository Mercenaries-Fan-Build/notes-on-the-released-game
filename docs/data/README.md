# Mercenaries 2 — Gameplay data (JSON schemas + UE5 import)

JSON schemas and example rows for mission contracts and overlay-driven spawning.
UE5 Editor Python loads examples into DataTables under `/Game/Mercs2/Data/Tables/`.

## Assets (created by `game-scripts/setup_data_structs.py`)

| Asset | Row struct | Purpose |
|-------|------------|---------|
| `DT_MissionRegistry` | `FMissionData` | Contract metadata + vz_state layer list |
| `DT_SpawnRegistry` | `FSpawnTableRow` | Entity name → Blueprint + overlay/trigger |
| `DT_TutorialMission` | `FMissionObjective` | Onboarding objectives (separate from contracts) |
| `DT_WeaponData` | `FWeaponData` | Weapon tuning stub |

Canonical field lists: `docs/data/mercs2_data_schema.json` (regenerated by setup script).

## Example vertical slice — PmcCon001

| File | Content |
|------|---------|
| `examples/pmccon001_mission.json` | Mission `PmcCon001` — layers, flow gate `VzaCon001`, objectives |
| `examples/pmccon001_spawn_table.json` | Six spawn rows (villa soldiers, spawner waves, hijack jeep, ammo) |

Schemas: `mission_data_schema.json`, `spawn_table_schema.json`.

## Editor workflow (no Blueprint required for this step)

Prerequisites: World Partition map, `populate_world.py` completed, struct fields authored on
`FMissionData` / `FSpawnTableRow` and bound as DataTable row structs (see setup log MANUAL lines).

### 1. Scaffold data assets

```
Tools → Execute Python Script → game-scripts/setup_data_structs.py
```

Finish any MANUAL enum/struct field authoring in the editor, then re-save tables.

### 2. Import JSON → DataTables

```
Tools → Execute Python Script → game-scripts/import_mission_data.py
```

Or set `MERCS2_SETUP_IMPORT_MISSION=1` before `setup_all.py`.

### 3. Populate world + default vz preset

```
game-scripts/import_world.py
game-scripts/populate_world.py
game-scripts/toggle_vz_visibility.py    # MERCS2_VZ_PRESET=act1_default (default)
```

### 4. Activate mission overlays (PMC baby step)

Minimal slice — only the base contract layer:

```
set MERCS2_MISSION_ID=PmcCon001
set MERCS2_MISSION_LAYERS=first
```

```
Tools → Execute Python Script → game-scripts/mission_layer_activator.py
```

Full contract (all five `tLayers`):

```
set MERCS2_MISSION_ID=PmcCon001
set MERCS2_MISSION_LAYERS=all
```

```
game-scripts/mission_layer_activator.py
```

### One-shot via `setup_all.py` (after world populate)

```
set MERCS2_MISSION_ID=PmcCon001
set MERCS2_MISSION_LAYERS=first
set MERCS2_SETUP_SKIP_IMPORT=1
set MERCS2_SETUP_SKIP_POPULATE=1
```

Run `setup_all.py` — runs import + activator after step 10 when `MERCS2_MISSION_ID` is set.
Skip with `MERCS2_SETUP_SKIP_MISSION=1`.

## PMC vertical slice — baby-step test sequence

1. **Data** — `setup_data_structs.py` → bind structs → `import_mission_data.py`
2. **World** — `import_world` + `populate_world` (Maracaibo subset or full world)
3. **Baseline visibility** — `toggle_vz_visibility.py` (`act1_default`: Act1 + pristine on)
4. **Mission layer** — `MERCS2_MISSION_ID=PmcCon001` `MERCS2_MISSION_LAYERS=first` → `mission_layer_activator.py`
5. **PIE** — Play in editor; Outliner → World Data Layers → confirm `VZ_Contract` and `VZ_pmccon001` activated
6. **Expand** — Re-run activator with `MERCS2_MISSION_LAYERS=all` to enable villa soldiers / hijack / spawner overlays

Expected without Blueprints: static mesh actors on mission overlays become visible when their
Data Layer activates (already placed hidden by `populate_world` for contract overlays).

Still requires Blueprint / C++ later: NPC spawn from `DT_SpawnRegistry`, objectives, rewards,
Lua `MrxTask*` flow, `ActivateMission` parity.

| `MERCS2_SETUP_SKIP_MISSION` | setup_all | off |

## Layer name mapping

Mission JSON uses WAD stems such as `vz_state_pmccon001`. The activator converts them to
populate_world leaf labels (e.g. `VZ_pmccon001`) via `mercs2_vz_taxonomy.data_layer_hierarchy`.

See `game-scripts/mercs2_mission_data.py` (`layer_stem_to_overlay_source`).
